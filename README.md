# STEVO Add-ons für Home Assistant

**STEVO Einrichtung** richtet einen neuen STEVO-Pi automatisch ein: Add-on starten, Code im STEVO Team-Panel unter „Neuer Pi“ eingeben, fertig.

[![Add-on hinzufügen](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FSteinzwerg%2Fstevo-addons)

Quelle: wird aus dem STEVO-Hauptrepo (Ordner `addon/`) hierher gespiegelt.
